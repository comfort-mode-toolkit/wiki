Contributing to Research
========================

We welcome research contributions from everyone. You don't need to be an academic or a senior engineer. You just need to be curious and thoughtful.

How to Submit a Proposal
------------------------

1.  **Fork the Repository:** Fork `comfort-mode-toolkit/cm-forms` (or the relevant repo).
2.  **Create a Branch:** Name it something descriptive, like `research/vestibular-motion`.
3.  **Write Your Findings:** Create a new markdown or RST file in the `research/` folder.
4.  **Cite Everything:** If you state a fact, link to the source. If it's from personal experience, state that clearly.
5.  **Use Plain Language:** Avoid jargon. If you must use a technical term, add it to the glossary below.
6.  **Open a Pull Request:** Submit your PR and tag it with `research`.

Writing Guidelines
------------------

*   **Be Clear:** Write as if you are explaining it to a friend who is smart but doesn't know this specific topic.
*   **Be Honest:** If you don't know something, say "We don't know yet."
*   **Be Kind:** Research is about learning, not proving others wrong.

Glossary
--------

.. glossary::

   Vestibular System
      The sensory system that provides the leading contribution to the sense of balance and spatial orientation for the purpose of coordinating movement with balance.

   Layout Shift
      When elements on a page move around unexpectedly, often causing users to lose their place or click the wrong thing.

   WCAG
      Web Content Accessibility Guidelines. The standard for web accessibility, but often just the starting point for true comfort.
