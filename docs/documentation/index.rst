Documentation
=============

*Making things clear for everyone*

----

.. toctree::
   :maxdepth: 1
   :hidden:

   writing-docs

Good documentation is the difference between a tool that's used and a tool that's ignored. We treat documentation as a first-class citizen.

What We Need
============

* **Tutorials:** Step-by-step guides for beginners.
* **Examples:** Real-world usage scenarios.
* **Copy Editing:** Fixing typos and clarifying confusing sentences.
* **Translations:** Making our tools accessible to non-English speakers.

Getting Started
===============

1. **Read the Style Guide:** Our :doc:`/meta-guide/style-guide` is your bible.
2. **Check the Structure:** Understand where things go with the :doc:`/meta-guide/wiki-structure`.
3. **Pick a Task:** Look for `documentation issues <https://github.com/comfort-mode-toolkit/cm-hub/issues?q=is%3Aissue+is%3Aopen+label%3A%22documentation%22>`_.

Tools We Use
============

* **Sphinx:** Our documentation generator.
* **reStructuredText (RST):** The markup language we use.
* **GitHub:** Where we collaborate.
