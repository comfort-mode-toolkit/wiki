=======
Testing
=======

*Breaking things so we can fix them*

----

Testing is vital. Accessibility tools that don't work are worse than no tools at all.

What We Test
============

* **Functionality:** Does the code do what it says?
* **Accessibility:** Is the tool itself accessible?
* **Usability:** Is it confusing?
* **Edge Cases:** What happens with weird inputs?

How to Help
===========

**Manual Testing**
   Download our tools and try to break them. Try using them with:
   * Screen readers
   * Keyboard only
   * High contrast modes
   * Zoomed in to 400%

**Automated Testing**
   Write unit tests and integration tests for our codebases.

**Reporting Bugs**
   When you find a bug, file an issue. Be specific:
   * What did you do?
   * What happened?
   * What did you expect to happen?
   * What browser/OS/assistive tech were you using?

----

*The best tester is someone trying to use the tool for real work.*
