Welcome, developer! Whether you're fixing a typo or architecting a new feature, we're glad you're here.

Where to Start
==============

1. **Get Set Up:** Follow our :doc:`setup` guide to get your environment ready.
2. **Understand the Flow:** Read our :doc:`workflow` guide to learn how we handle PRs and reviews.
3. **Find an Issue:** Look for `good first issues <https://github.com/comfort-mode-toolkit/cm-colors/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22>`_ in our repositories.

Our Repositories
================

* **cm-colors:** Our core color accessibility tool. Python-based.
* **cm-hub:** This documentation and community hub.
* **cm-web:** (Future) Web interface for our tools.

Principles
==========

* **Readable over clever:** Write code that others can understand.
* **Document as you go:** If you change logic, update the docstring.
* **Test everything:** If it's not tested, it's broken.
