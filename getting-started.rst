===============
Getting Started
===============

*Your first steps into the forest*

----

Welcome! If you're new here, this is the best place to start.

1. Read the Overview
====================
Check out our :doc:`index` page to understand our mission and values.

2. Choose Your Path
===================
We have different guides depending on what you want to do:

* **Want to write code?** Go to :doc:`contributing/code/index`.
* **Want to research?** Go to :doc:`contributing/research/index`.
* **Want to write docs?** Go to :doc:`contributing/documentation/index`.
* **Want to help the community?** Go to :doc:`contributing/community/index`.

3. Learn the Basics
===================
If you're new to accessibility, read our :doc:`a11y/index` guide. It explains the core concepts in plain language.

4. Join the Conversation
========================
We hang out in `GitHub Discussions <https://github.com/comfort-mode-toolkit/cm-hub/discussions>`_. Come say hi!
